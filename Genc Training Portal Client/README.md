# Training Management System - Frontend

This is the **Angular frontend** for the Training Management System.

## 📚 Full Documentation

Please see the **[Main README](../README.md)** for complete documentation including:
- Installation instructions
- Configuration guide
- Deployment instructions
- API documentation
- Troubleshooting

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm start

# Build for production
npm run build
```

Application runs on: **http://localhost:4200**

## ⚙️ Configuration

Edit `src/environments/environment.ts` to configure the backend API URL:

```typescript
export const environment = {
  production: false,
  apiBaseUrl: 'http://localhost:8080/api'
};
```

For more details, see the [Configuration Guide](../README.md#-configuration-guide) in the main README.
